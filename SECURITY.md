# Comunicar un problema de seguridad

Si encuentras una forma de acceder a archivos sin permiso, saltarse el
emparejamiento o instalar una actualización manipulada, utiliza
[el informe privado de GitHub](https://github.com/pepitolas13/PepoConnect/security/advisories/new).
Evita publicar primero los detalles en una incidencia abierta.

Incluye la versión, los sistemas afectados, los pasos para reproducirlo y el
impacto que hayas podido comprobar. Usa archivos de prueba, sin datos personales.

Las correcciones se preparan para la última versión estable. Si utilizas una
versión anterior, comprueba primero si el problema sigue ocurriendo al actualizar.
