# PepoConnect 0.4 — actualizar sin salir de la app

Esta versión hace más cómodo lo de todos los días: pasar una foto al ordenador,
enviar un archivo y seguir conectado sin estar pendiente de la ventana del móvil.

La novedad principal está en **Ajustes → Acerca de → Actualizar**. PepoConnect
comprueba una vez al día si hay una versión nueva. Al pulsar «Actualizar»,
descarga el paquete de tu sistema y lo verifica antes de instalarlo. Si prefieres
que no aparezca el aviso
en pantalla, puedes quitarlo en Notificaciones y seguir usando el botón cuando
quieras.

## También llega en esta versión

- Android puede mantener la conexión con la ventana cerrada mediante su servicio
  en segundo plano.
- El portapapeles compartido tiene un interruptor por pareja de dispositivos y
  accesos de Android para enviarlo desde los ajustes rápidos, el icono o Compartir.
- Los archivos ejecutables requieren permiso en los ajustes de cada dispositivo.
- Se han afinado las transiciones, los avisos de fotos nuevas y el sonido al
  completar las transferencias.

## Elige tu descarga

| Sistema | Archivo |
|---|---|
| Windows de 64 bits | `PepoConnect-win-x64.exe`; también hay un ZIP portable. |
| Android actual | `PepoConnect-android-arm64-v8a.apk`. El universal ARM sirve para combinar móviles ARM de 32 y 64 bits; hay un APK x86_64 aparte. |
| Linux | AppImage, Flatpak o tar.gz para x64 y ARM64. |
| iPhone | `PepoConnect-ios-unsigned.ipa`, para instalar con AltStore o Sideloadly. |

**Si vienes de 0.3 o anterior, instala 0.4 una vez manualmente.** El actualizador
nuevo queda preparado para las siguientes versiones. Conserva tus datos al
actualizar; no desinstales primero la app.

Windows y Linux AppImage/tarball se reinician para terminar. Android pide la
confirmación de su instalador y Flatpak abre el gestor de software. El IPA actual
de iPhone requiere volver a instalarlo con la misma cuenta de firma; iOS no
permite que ese paquete sin firmar se sustituya a sí mismo.

Los archivos siguen viajando por tu red local. GitHub se usa para comprobar las
versiones y descargar sus instaladores. `SHA256SUMS.txt` permite comprobar los
paquetes de esta publicación.
