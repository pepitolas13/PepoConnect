# PepoConnect 0.4.3

- Al pulsar Actualizar, la app vuelve a consultar la versión publicada antes de descargar. Una oferta guardada durante las últimas 24 horas ya no puede hacer que se instale de nuevo una versión obsoleta tras un intento fallido.
- Si esa comprobación falla, la app muestra el error y permite reintentar; no descarga silenciosamente el paquete antiguo.
- Los clics repetidos comparten una única comprobación y descarga. Se conserva la continuación de instalaciones Android que esperan un permiso.

Incluye las correcciones de galería y del actualizador de Windows de 0.4.1 y 0.4.2.

Si todavía utilizas 0.4.0, 0.4.1 o 0.4.2 y aparece una oferta antigua, pulsa primero **Comprobar actualizaciones** y después **Actualizar**. La versión nueva incorpora esa comprobación al propio botón Actualizar.
